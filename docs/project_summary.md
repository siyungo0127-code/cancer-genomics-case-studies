# Project Summary For Recruiters

This repository presents cancer genomics case-study work in a clean, reviewable GitHub format. It is designed to show how I organise bioinformatics work, communicate technical results, and think about reproducibility when working with sensitive clinical or genomic data.

Cancer genomics projects often involve large sequencing files, controlled-access patient data, and complex pipelines. For that reason, this repository does not include raw patient datasets. Instead, it includes a report artifact, a small example neoantigen summary table, and a lightweight Python script that demonstrates how included data can be summarised reproducibly.

The project is relevant to bioinformatics software developer roles because it connects cancer biology questions with practical software habits: clear repository structure, documented inputs and outputs, honest limitations, and code that can be run by another person. The biological themes include mutation interpretation, neoantigen prioritisation, tumour evolution, copy number alteration, immune microenvironment analysis, and clonality.

This should be read as a portfolio case-study repository, not as a production clinical pipeline or a complete reimplementation of upstream NGS workflows.
