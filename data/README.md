# Data

Raw clinical and genomic datasets are not included in this repository.

Reasons:

- Patient-level clinical and genomic data may be sensitive or controlled-access.
- Sequencing and genomics files can be too large for a lightweight GitHub portfolio repository.
- Large raw and intermediate files are better stored in controlled archives, object storage, or workflow-specific data platforms.

The `data/example/` directory contains small example files that are safe to inspect and suitable for lightweight reproducibility demonstrations. These files should not be treated as complete clinical datasets.
